# FocusSafe AI Chrome Extension

## Highlights

- Side-panel AI assistant (no focus loss)
- Scope / Context Modes:
  - 🧠 Chat only
  - 🌐 Current tab
  - 🪟 Screen (visible capture context)
  - 📄 Region (selection-priority mode)
- Focus modes: Focus / Silent / Assist
- Smart Context Engine with Context Ring:
  - active selection
  - current tab content
  - recent prompts/actions
  - page metadata
- Multi-response output:
  - Kurz
  - Detail
  - Schritt-für-Schritt
  - Code
- Privacy panel:
  - Pause AI access
  - Tab-only / full access
  - blocked domains list
- Memory controls:
  - off / session / persistent
  - forget current page
- Selection actions via right-click and floating mini-toolbar:
  - Erklären, Zusammenfassen, Übersetzen, Fix Code, Google it
- Hotkeys:
  - Alt+A open side panel
  - Alt+S capture + analyze
  - Alt+D explain selection
- Dev mode:
  - debug logs
  - prompt/response inspection

## Files

- `chrome-ai-assistant/manifest.json`
- `chrome-ai-assistant/background.js`

- `chrome-ai-assistant/sidepanel.html`
- `chrome-ai-assistant/sidepanel.css`
- `chrome-ai-assistant/sidepanel.js`

## Setup

1. Open `chrome://extensions`
2. Enable Developer mode
3. Load unpacked `chrome-ai-assistant/`
4. Open the extension side panel
5. Add API key per provider and test connection
